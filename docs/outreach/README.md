# Pilot outreach kit (Tier Wow — W.4)

**Owner:** Quentin (sales-side execution). This kit is the reusable
material — templates, pitch, quickstart — for landing 1–3 external
agent-dev pilots and capturing a testimonial for the hackathon
submission.

## What's here

- `OUTREACH_TEMPLATES.md` — cold-DM/email templates for three channels
  (LangChain Discord, X/Twitter DM, AutoGen Discord) + a warm-referral
  version. All are ≤ 4 sentences, non-generic, and end with one clear
  ask.
- `PILOT_PITCH.md` — one-page pitch deck (text) for the "why me, why
  now" conversation. Structured as Problem → Insight → Product → Why
  Casper → Pilot ask.
- `QUICKSTART_5MIN.md` — 5-minute integration path for an external
  agent-dev: `pip install`, one API key request, three code snippets
  (create → pay → dispute). Optimized for time-to-first-value.
- `TESTIMONIAL_INTAKE.md` — the 6 questions we ask a pilot user
  after 48 hours of usage. Answers get quoted verbatim in the
  hackathon submission (with permission).

## Success metric

**One (1) external agent-dev quoted in the hackathon submission page**
by demo day. That's what jury sees; that's what defensibility
argument looks like.

## Non-goal

Turning this into a scaled sales motion — that's post-hackathon. This
kit is the minimum viable proof that non-team humans use the SDK.
