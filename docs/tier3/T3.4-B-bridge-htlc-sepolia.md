# T3.4-B — HTLC Bridge on Real Sepolia (EVM leg)

**Status:** Deployed and verified on live Sepolia. Companion to T3.4-A
(in-memory deterministic mock at `server/bridge_htlc.py`) — the mock is
the *oracle*, this module is the truthful counterpart that drives an
actual EVM chain.

## What ships

- **`contracts/HTLC.sol`** — 128-line Solidity contract mirroring
  `bridge_htlc.py`'s state machine byte-for-byte (`EMPTY → LOCKED →
  CLAIMED | REFUNDED`). Uses **sha256** for the hashlock (not keccak256)
  so the same `(preimage, hashlock)` pair works on both the EVM leg and
  the Casper leg without adapter re-hashing.
- **`server/bridge_evm_adapter.py`** — Web3.py adapter: `evm_lock`,
  `evm_claim`, `evm_refund`, `evm_status`. Reads the deployment record
  from `docs/tier3/T3.4-B-deployment.json` and connects through a
  fall-through list of public Sepolia RPC endpoints (no vendor lock-in,
  no RPC key required for CI diff-test).
- **`scripts/deploy_htlc_sepolia.py`** — one-shot deploy script; wallet
  key is loaded from `~/.vault/vault.json`
  (`team.ae402_bridge_sepolia_testwallet`), never passed on the CLI.
- **`tests/test_bridge_evm_sepolia_integration.py`** — three network
  tests (`@pytest.mark.network`, deselected by default, run explicitly
  with `pytest -m network`).

## Diff-test with the T3.4-A mock (oracle-driven)

The mock (`bridge_htlc.py`) is the *deterministic reference implementation*.
For any `(preimage, hashlock=sha256(preimage), timelock)` triple:

| scenario | mock (T3.4-A) | Sepolia (T3.4-B) | verdict |
|----------|---------------|-------------------|---------|
| lock → claim(correct preimage) before timelock | `CLAIMED` | `CLAIMED` (tx succeeds) | ✅ match |
| lock → claim(WRONG preimage) | reject `preimage_mismatch` | revert `PreimageMismatch()` (selector `0x6f43bb63`) | ✅ match |
| lock → refund() before timelock | reject `timelock_not_expired` | revert `TimelockNotExpired()` (selector `0x621e25c3`) | ✅ match |
| lock → wait past timelock → claim | reject `timelock_expired` | revert `TimelockExpired()` (selector `0x7a6fcaa6`) | ✅ match |
| lock → wait past timelock → refund | `REFUNDED` | `REFUNDED` (tx succeeds) | ✅ match |
| double lock | reject `not_proposed` | revert `AlreadyLocked()` (selector `0x5f0ccd7c`) | ✅ match |
| claim after claim | reject `already_claimed` | revert `NotLocked()` (state ≠ LOCKED) | ✅ match |

All Solidity custom errors are decoded by
`bridge_evm_adapter._decode_revert()` back to their human name via
4-byte selector, so a caller can pytest.raises on `EvmAdapterError` and
`match=` against `"PreimageMismatch"` — same string handle as the mock's
`"preimage_mismatch"` rejection code, modulo case/naming.

## Design notes

- **Gas price floor of 5 gwei** — Sepolia public RPCs sometimes report a
  base fee below the mempool's actual min-inclusion floor, causing
  "replacement transaction underpriced" errors on rapid consecutive
  sends. 5 gwei is negligible on a testnet but reliably gets included.
- **Retry on underpriced replacement** — `_send` retries up to 3 times,
  doubling the gasPrice each time, so a slow-mining first tx doesn't
  block subsequent test steps.
- **`pending` nonce, not `latest`** — accounts for tx already broadcast
  but not yet mined so we don't collide with our own outstanding tx.
- **Custom-error decoding** — Solidity 0.8.4+ custom errors serialize as
  a 4-byte selector; `_build_selectors()` computes `keccak(name())[:4]`
  for every HTLC.sol error name and maps back to the human string so
  tests can assert on the readable name.
- **Secrets discipline** — private key is loaded lazily from
  `~/.vault/vault.json`, never logged, never included in commits, never
  passed as CLI arg. The `deploy_htlc_sepolia.py` script uses the same
  path; test fixtures mimic it.

## Migration path from T3.4-A (mock) to production

The `EvmSepoliaAdapter` interface (module-level functions with a passed-in
`Contract`) matches the shape of `bridge_htlc.py`'s pure state
transitions: swap the mock's `lock_leg` / `claim_leg` / `refund_leg` for
`evm_lock` / `evm_claim` / `evm_refund`, keep the same preimage/hashlock
material, and the swap orchestrator (T3.5) needn't change beyond
selecting which adapter to call per leg (mock for the Casper side, real
for the EVM side — or vice versa in a future rewrite).
